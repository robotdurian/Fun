# Sorting Hat — Simple Party Edition

**Flow (audio-only, run from a phone, speaker out):**
1. Child puts on the hat. Host taps **Wake the Hat** (or **Next child**).
2. Hat asks the child's name, listens, and confirms ("Did I hear… Luna?"). Child says yes, or says the name again. Host can type the name silently as a fallback.
3. Hat muses and quips: cold-read observations, a tempting decoy house, a "hold on…" doubt, then the real house's hint.
4. If the room gets noisy at any point the Hat pauses ("I can't hear very well with all this noise"), waits for quiet, then picks up where it left off. Host can tap ▶ to skip the wait.
5. "Better be… RAVENCLAW!" Then a house dare and "Next wizard, step forward!"

**Sorting:** there is no survey, so the house is chosen by the app: balanced across houses by default (random among the smallest teams), or fully random via ⚙.
**Setup:** serve over HTTPS (GitHub Pages / Netlify); Android + Chrome recommended; screen stays awake; ⚙ has voice picker, noise limit with live room check, and a spoken scoreboard.
Unofficial fan-made party game.
